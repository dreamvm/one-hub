# 令牌管理员操作与现有接口对齐

## 问题与边界（2026-10-04）

基线 `557103c95f2dd0acffb26000c2d4cbc62dd2c524`。本项从 main 独立分支，
不依赖 PR131 的文档提交，也不重开既往受限的安全审阅。

真实浏览器使用本机随机端口、临时 SQLite、合成管理员和普通账号发现：
管理员搜索他人令牌后，编辑已有管理员接口，但启停仍请求本人接口，删除菜单也仍显示。
`UpdateToken` 与 `DeleteTokenById` 按调用人 ID 查找令牌，所以他人删除返回 `record not found`。
这是界面操作与后端权限合同不一致，不是后端放行了他人删除。

## 最小修复

- 有管理员搜索条件时，启停调用已有 `/api/token/admin?status_only=true`；
  保留后端 `AdminAuth` 和状态检查。普通列表及无搜索条件时仍用本人接口。
- 管理员搜索他人令牌时隐藏删除菜单；本人令牌在普通和管理员搜索列表均可删除。
  不新增管理员删除接口，不修改后端所有权限制。
- 启停请求异常返回 `success: false`，避免行组件解构 `undefined` 产生未处理异常。
