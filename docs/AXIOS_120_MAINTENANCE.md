# Axios 1.20.0 维护候选

2026-10-04，基线 main `02116294c88db924e322eb8ebe6dca10009aecf8`。

## 定位与改动

这是普通依赖维护，不是已确认产品漏洞的修复。
[此前十二条公告核对](AXIOS_NEW_ADVISORIES.md)仍适用于受检浏览器调用：
当前仅有三个直接 Axios 消费者，没有新增 Node 服务、请求拦截器、自定义适配器或表单序列化入口。
一次 fresh 只读预调查与作者核对均未发现推翻该范围结论的证据；安全修复阶段结论为 `no_change`。
不人为引入产品未使用的模式来制造应用旧版失败证明。

维护候选将 Axios 1.18.0 固定升级到官方 1.20.0，保留浏览器 XHR 和 JSON 行为。
仅调整 package.json 和 Axios 锁条目，以及 form-data 的选择器 `^4.0.5` → `^4.0.6`；
后者实际版本原本就是 4.0.6，包地址和完整性不变。其他依赖条目不变。
独立的 `@types/node-fetch` → form-data 4.0.2 仍保留，不宣称所有同名库已更新。
