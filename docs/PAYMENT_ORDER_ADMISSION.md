# 支付订单创建边界

创建入口在外部支付前验证正数金额、有限折扣/费率、CNY/USD币种、分位精度及数据库金额范围；支付宝和微信仅允许CNY。额度使用精确乘法并检查正整数及本机int范围。普通费用继续沿用既有舍入规则，与当前页面保持兼容。

订单先写入数据库。插入失败不会调用网关；网关即时通知能找到原订单。外部超时或空响应不能证明支付没有创建，因此订单保持pending，后续已验证通知仍可结算，不以错误响应覆盖提前到达的成功通知。三小时本地关闭规则的延迟支付支持另批处理。

微信和Stripe请求均通过共享金额转换取得整数分；微信4.10元必须发送410分。正常优惠、固定/百分比手续费、USD不依赖人民币汇率、大额合法额度均有控制测试。

回归文件：`model/payment-admission_test.go`、`model/payment-native_test.go`、`payment/service_test.go`。本地SQLite/PostgreSQL通过；准确提交的MySQL及镜像结果另记NEXT_RELEASE。无schema变化，不修改锁文件，无真实支付请求。

回退会恢复外部支付早于本地订单及金额截断风险。历史不确定订单仍需核对，不自动退款或补款；本批不创建标签、发布镜像或部署生产。
