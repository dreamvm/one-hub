## 问题与修复

仪表盘 SupportModels 在初次 effect 的闭包中捕获厂商元数据。StatusContext 独立获取该元数据，因此它晚于模型响应、或在模型请求中途到达时，模型列表会一直保留旧顺序。初始元数据已齐的明暗正常对照通过，而两种延迟顺序均失败。

effect 内仅取模型、分组并排序各厂商的模型名称；渲染阶段按当前 Redux 元数据计算厂商顺序。元数据变化不重新请求模型，也不重置展开状态。active 标记忽略已清理 effect 的结果与错误。保留正常复制、模型图标、错误提示和未知厂商默认排序规则，没有调整其他页面或新增依赖。
