# 个人抽屉入口与焦点恢复

2026-10-03，基于 main `9480a9d4dcaa35a5be6028df5cdbd38f6f7da0d7`。

## 问题与修复

本地真实后端浏览器验收发现：退出个人抽屉时，Chrome 报告抽屉内部仍保留焦点，
因而阻止对其祖先设置 `aria-hidden`。头像入口原为带点击事件的 `div`，既不能通过
键盘正常激活，也不能作为 MUI 抽屉关闭后的焦点恢复目标。

将入口替换为 MUI `IconButton`，沿用已有 `profile` 翻译作为可访问名称，保留原有
头像、尺寸、渐变和回调。移除头像上未使用的 ref。未关闭 MUI 焦点约束，也未以
隐藏警告、全局 blur 或更改注销请求来规避问题。
