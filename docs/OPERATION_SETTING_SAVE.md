# 运营设置保存结果与刷新状态

2026-10-01 独立候选，基于PR #93合并0f50ed877c91dd9b645c9005e00f388df1f052ff；尚未完成本项准确候选CI、PR与合并。

## 问题和修复

运营设置的单项保存吞掉写入失败，调用方仍报告成功；组保存也会继续写下一项并错误报整体成功。单项异常可让页面停留在loading，多项保存则由每个子请求提前解除loading。Payment/Claude组在写入前一个字段后才校验后一个JSON字段。

单项函数只在服务端确认成功后更新本地值，失败抛出交给所属整次保存处理；checkbox与组保存各自管理loading和finally，保存期间禁用checkbox及保存按钮。组保存遇到失败中止后续写入，已确认的前项不回滚，并明确提示部分保存；同组JSON先校验再写。合并每项重复的options/status刷新为整次末尾刷新，写入已确认但刷新失败时报告需要重新加载核对。

这些接口仍逐项保存，不是事务；网络响应丢失不能证明服务端未写入，不自动重试或撤销。不覆盖真实并发管理员更新、生产配置、未展示设置的完整语义或请求取消。
