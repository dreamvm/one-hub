## 问题与最小修复

首页请求拒绝或共享 Axios 拦截器返回 undefined 时，原 catch 直接返回，loaded 永远为 false。旧版回归两个正常对照通过，网络异常检查失败，实际留下 CircularProgress。另一个旧判断以成功内容是否等于当前错误译文决定错误状态，会把合法同名内容误判成失败。

请求移入挂载 effect，独立记录错误状态，在 finally 结束加载。active 标记防止卸载或 StrictMode 清理后的结果更新内容、缓存或通知；不修改共享拦截器。删除原本只在加载遮罩下赋值且不会作为成功结果使用的缓存读取，保留成功响应写入缓存。请求仍沿用共享 API 既有超时策略；未响应且始终不结束的请求不在本次异常完成修复范围内。
