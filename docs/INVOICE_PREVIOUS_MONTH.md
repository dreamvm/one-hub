# 月末自动账单选择上月

## 问题与修复

`InsertStatisticsMonth` 原先先对今天执行 `AddDate(0,-1,0)`，再取该结果所在月份的一日。
当上月没有对应日号时，日期归一化可能回到本月；例如2026-03-31会落到三月，进而选择
三月一日，生成尚未结束的本月账单，或把本月已有历史误当成上月已完成。

启用月账单时启动路径会调用该函数；定时任务源码使用每日04:00的 `DailyJob`，
虽然旁边旧注释写“每月一号”，实际并非只会在一号调用。不能用该注释排除月末路径。

修复直接使用 `time.Date(now.Year(), now.Month()-1, 1, ...)` 选择上月一日，仍沿用本地时区、
既有历史检查及汇总函数。入口依旧使用 `time.Now()`；增加私有带时间参数的实现，
测试通过只编入测试二进制的导出包装传入固定日期，不改变生产接口或定时频率。
