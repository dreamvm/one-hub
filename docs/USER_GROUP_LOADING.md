## 问题与最小修复

`useLogin.loadUserGroup` 在同步try/catch内启动Promise链，但没有为链添加拒绝处理。网络异步拒绝或共享拦截器返回undefined后解析响应抛错，都会成为未处理拒绝。原真实hook回归一项正常通过、一项失败并记录一次未处理拒绝。

仅为原Promise链添加catch，沿用既有console.error处理方式，并补充稳定Redux dispatch依赖。保留同步返回空数组、成功写入用户组、业务失败不覆盖已有用户组；所有登录、UserContext及Token调用方均不依赖请求Promise。未修改鉴权、登录/OIDC协议、共享拦截器、自动重试或请求超时，也未合并现有UserContext与Token重复加载调用。
